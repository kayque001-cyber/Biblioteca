Biblioteca Escolar é um sistema web desenvolvido para facilitar o gerenciamento e a consulta do acervo de uma biblioteca escolar.
A aplicação foi desenvolvida utilizando Python e Django, com SQLite para armazenamento dos dados e Bootstrap 5.3.8 junto ao CSS personalizado para a construção de uma interface organizada e responsiva.

O sistema permite cadastrar, editar, excluir e consultar livros, além de realizar pesquisas por título, autor e categoria.
Também é possível visualizar informações detalhadas de cada livro, incluindo autor, editora, ISBN, ano de publicação, categoria, quantidade de exemplares, disponibilidade e capa do livro.

O projeto também conta com o Django Admin, utilizado para o gerenciamento do acervo e dos dados cadastrados.
A aplicação foi desenvolvida como projeto acadêmico do curso de Programador Back-End Python, na Unidade Curricular de Desenvolvimento Web com Django.
